# MagicShieldTweaks
Simple mod that improves the magic shields you can cast. Adds secondary attacks to both staffs that allow you to remove the shield they cast and changes color of the protection shield based on its current health. All configurable.

**Server-Side Info**: This mod is entirely client side.

## Instructions
If you are using a mod manager for Thunderstore simply install the mod from there. If you are not using a mod manager then, you need a modded instance of Valheim (BepInEx) and the Jotunn plugin installed.

## Configuration
Changes made to the configuration settings will be reflected in-game immediately (no restart required). The mod also has a built in file watcher so you can edit settings via an in-game configuration manager (changes applied upon closing the in-game configuration manager) or by changing values in the file via a text editor or mod manager.

- AddStaffSecondaryAttacks: Whether to add secondary attacks to staffs that provide a shield-like status effect that allows you to remove the status effect.
- ChangeShieldColorByHealth: Whether to change the color of your shield based on its current health
- PreventZeroDamageShieldSpam: If you take 0 damage to your shield then prevent the hit effect from playing. Could prevent occasional hit effect spam.
- PreventLookVectorConsoleSpam: If shield takes damage from an indirect hit then the 'Prevent Look Rotation Viewing Vector Is Zero' will no longer be shown in log file or console.
